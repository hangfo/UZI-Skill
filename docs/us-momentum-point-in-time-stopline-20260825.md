# US 动量点时宇宙门禁与真实热门股复验（2026-08-25）

## 结论先行

本轮没有发现足以修改 UZI 生产评分、动量、Stage、P0/P1、估值或交易阈值的证据。
六只当日热门/高活跃美股的真实 Yahoo 复验显示，现有系统没有因为单日热度自动给出
买入结论；但十年历史结果在时间切片间显著翻转，且样本是“今天仍上市且今天热门”的
后见选择，不能用于调参。

因此，本轮采纳的是研究治理改进：`tools/us_momentum_walkforward.py` 现在默认把手选或
当前榜单样本标记为 `selected_universe_only`，并明确输出
`parameter_tuning_allowed=false`。只有来源可追溯、无前视、完整包含退市证券的点时
历史宇宙清单通过契约后，工具才允许把结果视为参数研究证据。

## 第一性原理判断

可交易信号的历史验证至少需要同时满足：

1. 在每个历史时点只使用当时可知信息；
2. 证券宇宙包含后来退市、并购或破产的成员；
3. 不能按今天的热门股、幸存者或已知赢家倒选样本；
4. 全部宇宙成员都要有成功获取的价格，失败不能静默丢弃；
5. 交易成本、下一交易日入场及非重叠采样必须明确；
6. 时间外切片的方向和量级不能发生无法解释的翻转。

当前可授权使用的 Yahoo/东财榜单只能给出当前证券或当前热度，SEC 官方数据也不是完整的
历史上市/退市成员数据库。Massive 仍受既定边界约束，仅作非覆盖式 EOD shadow，不能为了
回测扩张用途。缺少合格点时宇宙时，正确动作是停止优化，而不是用幸存者样本制造精确幻觉。

## 代码与测试修缮

### 点时宇宙契约

新增可选 `--universe-manifest`，合格清单必须：

- 使用 `uzi.us_point_in_time_universe.v1` schema；
- 来源类型为官方历史上市档案或获许可的点时数据库，并提供来源名和 URL；
- 显式声明 `lookahead_free=true`、`includes_delisted=true`、`complete_universe=true`；
- 为每只证券提供有效的生效/失效区间，且至少有一个有限区间证明退市覆盖；
- 清单宇宙与请求宇宙完全一致，任一成员取价失败即不允许调参；
- 信号日期不在成员有效期内时直接排除。

新增四个对抗测试覆盖：无清单 fail closed、合格清单可通过、缺退市覆盖被拒绝、退市后
信号被过滤。这些构造数据只验证契约，不承担任何收益结论；收益结论全部来自下述真实行情。

### 既有测试债清理

上轮全量直接测试剩余的 7 个失败均属于已变化契约或 Windows 测试隔离问题，而非生产回退：

- 全球交易所从模糊 `G` 收敛为 `SE/JP/TW` 后，同步旧断言；
- 市值展示统一为一位小数后，同步展示断言，原始精度仍保留；
- Windows spawn 测试改为在测试内联执行，使 monkeypatch 确定性生效；生产进程隔离不变；
- POSIX 可执行位与 WSL Bash 语法断言仅在 POSIX 运行，Windows 上跳过。

全量可直接运行测试由上轮 `673/680` 提升到 `684/684`。另有 13 个显式依赖 pytest 的
文件因当前 venv 未安装 pytest 而未运行；遵守边界，没有为此安装依赖。

## 取舍与后续门槛

保留：

- Stage 作为风险护栏和报告解释，不把它变成单独交易策略；
- 真实榜单小样本作为压力测试和异常发现器；
- 点时宇宙 manifest、完整性、退市覆盖、取价失败和有效期过滤门禁；
- 冻结输入重放、时间切片和 SPY 超额比较。

搁置或放弃：

- 基于当前热门股提高动量权重或改变 Stage 阈值；
- 用当前 Yahoo/东财上市列表假装历史完整宇宙；
- 为追求回测覆盖扩张 Massive、CBOE 或 TradingView 非官方接口用途；
- 根据本轮不同日期报告分差修改评分。

只有未来取得可审计、获授权、包含退市证券的完整点时美国股票宇宙，并在预注册的时间外
验证中获得跨制度稳定、扣费后仍为正且不由少数发行人主导的结果，才重新讨论参数研究。

## 边界

- 未访问 CBOE，未接入 TradingView 非官方接口；
- 未暴露、记录或提交凭据；SEC 未在缺少真实身份时联网；
- Massive 仍仅作 EOD shadow，FRED 仍为 evidence-only；
- SEC Item 4.01 仍按正文语境 shadow，没有多个独立官方样本时不自动归类负面；
- 未修改生产评分、动量、Stage、P0/P1、估值或交易阈值；
- `main`、`codex/windows-local-stable` 未修改，`upstream` push 保持禁用。
